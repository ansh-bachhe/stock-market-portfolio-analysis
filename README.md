# 📊 Stock Market Data Analysis

**Tools Used:** Power BI | MySQL  

---

## 📌 Problem Statement
Investors and portfolio managers often face challenges in understanding market behavior due to large volumes of stock trading data spread across multiple companies and sectors.  
Without proper analysis and visualization, it becomes difficult to evaluate portfolio performance, identify high-performing sectors, measure risk, and assess the effectiveness of trading strategies.

This project aims to solve this problem by transforming raw stock market data into meaningful insights using SQL and interactive dashboards.

---

## 🎯 Project Objectives
- Analyze historical stock market trading data across multiple companies and sectors  
- Evaluate overall portfolio performance using key financial metrics  
- Identify high-performing and underperforming sectors and companies  
- Measure trading efficiency using KPIs such as win rate and volatility  
- Provide actionable insights to support data-driven investment decisions  

---

## 📌 Project Overview
This project focuses on analyzing stock market performance using historical trading data.  
SQL was used to extract, transform, and aggregate data, while Power BI was used to create interactive dashboards that visualize key market and portfolio metrics.

The analysis helps stakeholders quickly understand market trends, portfolio allocation, and risk-return behavior.

---

## 🛠 Tools & Technologies
- **Power BI** – Interactive dashboards and visual analytics  
- **MySQL** – Data extraction, transformation, and KPI calculations

## 🔍 Key Insights
- Information Technology sector generates the highest profit and return  
- Nearly 50% of total trading volume comes from the IT sector  
- Companies like Pfizer Inc. and Amazon Inc. show higher daily returns  
- Financial sector underperforms compared to other sectors  
- High trade win rate indicates an effective trading strategy  

---

## 📌 Business Recommendations
- Increase exposure to high-performing sectors such as IT  
- Reduce allocation to high-volatility stocks  
- Increase trading activity during high-volume months  
- Continuously monitor volatility trends to manage risk
